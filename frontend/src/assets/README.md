## Usage Notes
- All SVGs are fully scalable — use at any size
- Transparent background files (.svg) work on any background
- For web: use SVG directly or export to PNG at required size
- For print: export to PDF or EPS via Figma/Illustrator
- Minimum logo size: 120px wide for horizontal lockup, 80px for mark only
- Font used in wordmark: Pinyon Script (Google Fonts) — install before opening in design tools

## Font Installation
Wordmark font: Pinyon Script
Download free at: https://fonts.google.com/specimen/Pinyon+Script
Install system-wide before opening SVG files in Illustrator or Figma.
